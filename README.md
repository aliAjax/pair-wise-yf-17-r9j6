# hxyfront-62005 管风琴音管调音台

给管风琴维护人员使用的音管调音记录应用（React + Vite + TypeScript）。

## 功能

- **单次调音录入**：场馆（教堂/音乐厅）、音栓、音管编号、音高、音分偏差（偏高为正）、
  现场温度、相对湿度、簧片状态、维修备注。
- **异常自动判定与冻结**：以「场馆 + 音栓 + 音管编号」唯一标识一根音管，
  当同一音管连续两次调音偏差方向相同且绝对值扩大时，自动标记异常并冻结该音管的后续调音
  （表单拦截 + 行内标红 + 指标/页签红点）。
- **现场复核解冻**：冻结音管只有在异常页写出具体现场复核结论（≥10 字，需写明原因、处置与复测）
  才能解除冻结；解冻后异常历史永久保留；之后若再次同向扩大将重新冻结。
- **偏差表**：全部调音记录，正负偏差分色，异常链行高亮，异常判定引用的记录不可删除。
- **温湿度记录**：每次维护的温湿度同步落表，给出维护区间评估（适宜 15–22℃ / 45–60%）与均值。
- **单次维护报告**：按「场馆 + 日期」自动归集一次维护，含环境均值、最大偏差、调音明细、
  异常与处置、签字栏，可打印或另存为 PDF。
- **音栓 / 场馆筛选**：侧栏筛选与偏差表、温湿度、报告、异常页同步联动。
- **本地持久化**：所有数据仅存浏览器 `localStorage`（键 `organ-tuning-console:v1`），
  刷新保留；支持载入演示数据与清空本地数据，无后端、无网络上传。
