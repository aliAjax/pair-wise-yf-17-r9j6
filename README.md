# hxyfront-62005 管风琴调音台

给管风琴维护人员使用的音管调音记录前端：逐次维护记录场馆、音栓、音管编号、音高、音分偏差、温湿度、簧片状态与维修备注，自动识别持续跑偏的音管并冻结其后续调音。

## 功能

- **维护录入**：一次维护可归入已有报告或新建报告（场馆、日期、维护人、概述）；支持现场新增音栓（类型/标称音管长度）。
- **异常自动判定**：同一音栓的同一音管，连续两次测量的音分偏差同向且绝对值严格扩大时，自动生成异常事件并**冻结该音管后续调音**（录入表单对冻结音管禁用保存并提示）。
- **复核解冻**：冻结只能在「异常音管」页凭**具体现场复核结论**解除（去空白后 ≥ 10 字，"已处理/正常"无法通过）；解冻后异常历史永久保留并标注已复核。
- **调音偏差表**：时间、场馆、音栓、音管、偏差、相对上一条的趋势、簧片状态；冻结行红色、|偏差| ≥ 10 cent 标单次超限。
- **温湿度记录**：每条测量对应的温湿度条形记录与平均值。
- **单次维护报告**：按报告汇总当次场馆、维护人、测量音管数、平均温湿度与明细表，可打印 / 存为 PDF。
- **音栓筛选**：侧边音栓列表与搜索框，偏差表、温湿度、录入面板同步联动。
- **本地持久化**：数据只存浏览器 `localStorage`（键 `organ-tuning-console:v1`），刷新/重开保留；支持导出 JSON 与一键清空重置（恢复演示数据）。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无额外运行时依赖。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62005，访问 http://localhost:62005

## 数据模型

- `Stop`：场馆、音栓名、类型（主音栓/簧片音栓/混合音栓/低音管）、标称音管长度
- `Report`：一次维护（场馆、日期、维护人、概述）
- `Measurement`：单次测量（音管编号、音高、音分偏差、温度、湿度、簧片状态、备注）
- `Incident`：异常事件（触发的前后两次测量、冻结状态、解冻复核结论与时间，解除后仍保留）

首次打开内置演示数据：Bourdon 16' 的 F2 已因 -8 → -14 cent 连续同向扩大被自动冻结，可直接走一遍"复核解冻"流程。
